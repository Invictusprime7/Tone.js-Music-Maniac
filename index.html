Architecture Overview

This application leverages Tone.js, a powerful Web Audio API framework, to create various synthesizers and audio effects. The architecture consists of:

  • Synthesizers: DuoSynth, MembraneSynth, NoiseSynth, MonoSynth
  • Effects: Low-pass filtering for kick drum processing
  • Sequencing: Pattern-based rhythmic sequences using Tone.Part
  • Transport: Global timing and synchronization system

Technical Implementation

Each instrument demonstrates different synthesis techniques:

  • Synth: Uses dual oscillators for rich harmonic content
  • Kick: MembraneSynth with envelope shaping and low-pass filtering
  • Snare: White noise synthesis with rapid envelope decay
  • 808: MonoSynth with triangle wave for characteristic bass sound
